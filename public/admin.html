Configuração da pesquisa

Cole o link do formulário de cada grupo (cada formulário tem os 2 vídeos e os 2 questionários). Enquanto os dois links não forem preenchidos, a pesquisa fica fechada para os participantes.

Dica: use o link "preenchido" do Forms com o código do participante trocado por {codigo}. O site coloca o código de cada pessoa no lugar automaticamente.

Resumo: participantes por nível e grupo
